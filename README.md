# Personal Expense Tracker

My first Python project! This application helps users record and manage their daily expenses.

## Features
- Add expenses
- Choose expense categories
- Save expenses in a CSV file
- View expense history
- Calculate total spending
- View category-wise totals
- Delete expenses with confirmation
- Validate user input

## Technologies Used
- Python
- CSV file handling
- Visual Studio Code

## How to Run
Run the `expense_tracker.py` file using Python 3.

## What I Learned
- Python programming basics
- Functions and loops
- Input validation
- Reading and writing CSV files
- Building a practical project

## Privacy
Personal expense records are stored locally. The `expenses.csv` file is excluded from this repository to protect private information.
